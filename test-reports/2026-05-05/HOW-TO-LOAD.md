# Как увидеть прогнанные сценарии в UI

Сценарии прогнаны через реальный backend, всё содержимое (сообщения и карточки) сохранено в `sessions.json`. Чтобы увидеть их **в сайдбаре `localhost:3000` как обычные чаты**, нужно один раз вставить эти сессии в `localStorage` твоего браузера.

## Шаг 1. Запусти оба сервиса (если ещё не запущены)

```bash
# терминал 1 — backend
cd backend && python3 app.py

# терминал 2 — frontend
cd frontend && npm run dev
```

Открой `http://localhost:3000` в Chrome (рекомендуется обычный профиль, не incognito — чтобы `localStorage` пережил перезагрузку).

## Шаг 2. Загрузи сессии в браузер

Открой DevTools (`Cmd+Opt+I` на Mac / `F12` на Win), вкладка **Console**, вставь:

```js
fetch("/test-sessions.json").then(r => r.json()).then(s => {
  localStorage.setItem("navylet_sessions", JSON.stringify(s));
  console.log(`✓ Загружено ${s.length} сессий. Перезагружаю страницу...`);
  setTimeout(() => location.reload(), 500);
});
```

Готово — после reload в левом сайдбаре появятся **13 чатов** с реальными сообщениями, карточками туров, recommend/match-бейджами, share-ссылкой и т.д.

## Шаг 4. Открой share-ссылку из Сц.7 — увидишь счётчик в Сц.7 в сайдбаре

После Шага 2 открой:

```
http://localhost:8090/share/d3ebe7ced199
```

(она уже открывалась дважды во время прогона — `views=2, unique=1`). Email-вариант той же подборки:

```
http://localhost:8090/share/d3ebe7ced199/email
```

В UI зайди в раздел **«Коллекции»** → увидишь зелёный бейдж `👁 N · 👥 M` рядом с подборкой.

## Очистка

Чтобы убрать тестовые сессии и вернуться к чистому состоянию:

```js
localStorage.removeItem("navylet_sessions");
location.reload();
```
